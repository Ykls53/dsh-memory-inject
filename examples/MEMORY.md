项目根目录 D:\workspace\my-app；改配置前先备份到 .backup\ 并留回退命令。

§

本地服务监听 127.0.0.1:8080；端口是动态分配的，别写死，用 netstat 现查。

§

配置改完要跑 node tools\check-config.mjs，全绿才能重启客户端。

§

.env 在项目根目录，里面是 API key。改它能影响联网；**重启进程后才会被重新读取**。

§

构建产物在 dist\；日志在 logs\app.log；出问题先看日志尾部 50 行。
